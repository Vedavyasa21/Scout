# Code of conduct

## Our pledge

We want Scout to be a welcoming project for everyone, regardless of experience,
identity or background. We pledge to make participation harassment-free.

## Expected behavior

- Be respectful and assume good intent.
- Give technical critique about code and ideas, not people.
- Accept feedback gracefully and ask questions when unsure.
- Respect privacy: do not ask others to share API keys, personal paths or logs
  containing personal data.

## Unacceptable behavior

- Harassment, insults, discrimination or sexualized language.
- Publishing others' private information without permission.
- Deliberately introducing insecure code, hidden data collection or backdoors.
- Sustained disruption of discussions or reviews.

## Scope

This applies in all project spaces: issues, pull requests, discussions and any
project-related communication.

## Enforcement

Maintainers may warn, edit or remove contributions and temporarily or permanently
ban participants. Report concerns privately to the maintainers; reports are handled
confidentially.

This document is adapted from the Contributor Covenant, version 2.1.
